# Primeros pasos

1. Abra la aplicación: en el primer inicio aparece el **asistente de bienvenida**.
2. Elija **idioma**, **tema** y **motor** (introduzca la clave API si es necesaria).
3. Abra un **EPUB** con *Abrir EPUB…*.
4. Establezca el **idioma de origen** (o *Auto detect*) y el **destino**.
5. Pulse **Traducir**. Observe el progreso animado.

El archivo traducido se guarda junto al original como `libro-<idioma>.epub` (el sufijo `-<idioma>` se añade automáticamente;
si el archivo ya existe, la app pregunta antes de sobrescribirlo).
