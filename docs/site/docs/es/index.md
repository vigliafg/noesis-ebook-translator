# Noesis Ebook Translator

Traduce libros **EPUB** a otro idioma conservando **formato, índice, enlaces e
ilustraciones**. El motor proviene del
[plugin de Calibre](https://github.com/bookfere/Ebook-Translator-Calibre-Plugin)
de bookfere (GPLv3).

## Funciones

- Interfaz en **5 idiomas** (italiano, inglés, francés, español, alemán).
- **Temas** (sistema, claro, oscuro).
- **Asistente de bienvenida** en el primer inicio, reabrible desde Configuración.
- Lector EPUB integrado con búsqueda, temas y vista paralela.
- **Biblioteca** persistente con posición de lectura y capítulos traducidos.
- **Exportación** a EPUB, HTML, Markdown, TXT, JSON, CSV, DOCX y PDF.
- **Evaluación de calidad** (métricas + juez de IA).
- Herramientas **split/merge** y **editores** de textos, imágenes y tablas.

Ver [Primeros pasos](getting-started.md) y las [Preguntas frecuentes](faq.md).
