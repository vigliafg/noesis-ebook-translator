# Preguntas frecuentes

## ¿Necesito una clave API?
Solo para los motores que la requieren (Gemini, ChatGPT, Claude, DeepL, …). Los
motores gratuitos de Google, DeepL Free y Microsoft Edge funcionan sin clave.

## ¿Dónde se guardan la biblioteca y los capítulos?
En una base de datos SQLite en el directorio de configuración
(`~/.config/noesis-ebook-translator` en Linux).

## ¿Puedo traducir solo algunos capítulos?
Sí: marque capítulos en el índice del lector o use el filtro
(p. ej. `1,3,5-7`) en la vista previa y la exportación.
