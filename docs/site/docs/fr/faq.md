# FAQ

## Faut-il une clé API ?
Uniquement pour les moteurs qui l'exigent (Gemini, ChatGPT, Claude, DeepL, …).
Les moteurs Google gratuits, DeepL Free et Microsoft Edge ne nécessitent pas de clé.

## Où sont stockées la bibliothèque et les chapitres ?
Dans une base SQLite du répertoire de configuration
(`~/.config/noesis-ebook-translator` sous Linux).

## Puis-je traduire seulement certains chapitres ?
Oui : cochez les chapitres dans l'index du lecteur, ou utilisez le filtre
(par ex. `1,3,5-7`) dans l'aperçu et l'export.
