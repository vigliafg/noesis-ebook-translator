# Démarrage

1. Ouvrez l'application : au premier lancement, l'**assistant de bienvenue**
   apparaît.
2. Choisissez **langue**, **thème** et **moteur** (saisissez la clé API si besoin).
3. Ouvrez un **EPUB** avec *Ouvrir un EPUB…*.
4. Définissez la **langue source** (ou *Auto detect*) et la **cible**.
5. Cliquez sur **Traduire**. Regardez la progression animée.

Le fichier traduit est enregistré à côté de l'original sous `livre-<langue>.epub` (le suffixe `-<langue>` est ajouté automatiquement ;
si le fichier existe déjà, l'app demande avant de le remplacer).
