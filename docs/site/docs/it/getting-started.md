# Introduzione

1. Apri l'app: al primo avvio compare il **wizard di benvenuto**.
2. Scegli **lingua**, **tema** e **motore** di traduzione (inserisci la chiave API
   se richiesta).
3. Apri un **EPUB** con *Apri EPUB…*.
4. Imposta **lingua di origine** (o *Auto detect*) e **destinazione**.
5. Premi **Traduci**. Segui il progresso animato; a fine corsa apri il file.

Il file tradotto viene salvato accanto all'originale come
`libro-<lingua>.epub` (il suffisso `-<lingua>` viene aggiunto in automatico;
se il file esiste già l'app chiede conferma prima di sovrascriverlo).
