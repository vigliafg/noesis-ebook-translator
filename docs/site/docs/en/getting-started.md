# Getting started

1. Open the app: on first run the **welcome wizard** appears.
2. Choose **language**, **theme** and **translation engine** (enter the API key
   if required).
3. Open an **EPUB** with *Open EPUB…*.
4. Set the **source language** (or *Auto detect*) and the **target**.
5. Press **Translate**. Watch the animated progress; open the file when done.

The translated file is saved next to the original as `book-<language>.epub` (the `-<language>` suffix is added automatically;
if the file already exists the app asks before overwriting it).
