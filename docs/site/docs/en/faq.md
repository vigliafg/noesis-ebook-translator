# FAQ

## Do I need an API key?
Only for engines that require one (Gemini, ChatGPT, Claude, DeepL, …). The free
Google engines, DeepL Free and Microsoft Edge work without a key.

## Where are the library and chapters stored?
In a SQLite database in the app config directory
(`~/.config/noesis-ebook-translator` on Linux).

## Can I translate only some chapters?
Yes: check chapters in the reader index, or use the chapter filter
(e.g. `1,3,5-7`) in preview and export.
