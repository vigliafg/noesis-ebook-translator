# Noesis Ebook Translator

Translate **EPUB** books into another language while keeping **formatting,
index, links and illustrations**. The translation engine is taken verbatim from
bookfere's [Calibre plugin](https://github.com/bookfere/Ebook-Translator-Calibre-Plugin)
(GPLv3).

## Features

- Interface in **5 languages** (Italian, English, French, Spanish, German).
- **Themes** (system, light, dark) applied across the app.
- **Welcome wizard** on first run, relaunchable from Settings.
- Built-in EPUB reader with search, themes and a parallel view.
- Persistent **library** with reading position and translated chapters.
- **Export** to EPUB, HTML, Markdown, TXT, JSON, CSV, DOCX and PDF.
- Translation **quality evaluation** (metrics + AI judge).
- **Split/merge** tools and **editors** for texts, images and tables.

See [Getting started](getting-started.md) and the [FAQ](faq.md).
