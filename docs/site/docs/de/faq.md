# FAQ

## Brauche ich einen API-Schlüssel?
Nur für Engines, die einen benötigen (Gemini, ChatGPT, Claude, DeepL, …). Die
kostenlosen Google-Engines, DeepL Free und Microsoft Edge funktionieren ohne.

## Wo werden Bibliothek und Kapitel gespeichert?
In einer SQLite-Datenbank im Konfigurationsverzeichnis
(`~/.config/noesis-ebook-translator` unter Linux).

## Kann ich nur einige Kapitel übersetzen?
Ja: markieren Sie Kapitel im Leser-Index oder nutzen Sie den Kapitelfilter
(z. B. `1,3,5-7`) in Vorschau und Export.
