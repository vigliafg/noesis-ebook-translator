# Erste Schritte

1. Öffnen Sie die App: beim ersten Start erscheint der **Willkommensassistent**.
2. Wählen Sie **Sprache**, **Design** und **Engine** (API-Schlüssel falls nötig).
3. Öffnen Sie eine **EPUB** über *EPUB öffnen…*.
4. Legen Sie **Ausgangssprache** (oder *Auto detect*) und **Zielsprache** fest.
5. Klicken Sie auf **Übersetzen**. Beobachten Sie den animierten Fortschritt.

Die übersetzte Datei wird neben dem Original als `buch-<sprache>.epub` (das Suffix `-<sprache>` wird automatisch angehängt;
existiert die Datei bereits, fragt die App vor dem Überschreiben nach) gespeichert.
